# MB.42.2.0 — Result

## Pinned Ordering & Ownership (`docs/design/universal-distribution.md` §1.2.1)

- **`Embed` (universal binary; shim owns CPython):** `test_swap_pause` -> `fstat` `(st_dev, st_ino)` re-verify on `(lib_fd, shim_fd)` -> `fork(http)` (`hooks = None`) -> `fork(scheduler)` (`hooks = None`) -> `dlopen("/proc/self/fd/<lib_fd>", RTLD_NOW | RTLD_GLOBAL)` -> `dlopen("/proc/self/fd/<shim_fd>", RTLD_NOW | RTLD_LOCAL)` -> `blastit_py_abi_v1()` (`abi_version`/`py_minor`) -> `vtable.init_paths` (`Py_InitializeEx(0)` keeping GIL held on Stage 1's sole thread) -> `hooks = Some(loaded.hooks())` (`Serve` `visibility::{unreadable,writable}` forks) -> `vtable.preload` (`LoadedTracker` pre-fork when `report_fd >= 0` -> `*mut PyZygoteOpaque`) -> per-view `fork` via `blastit-view::spawn::Forker` (`before_fork` -> `blastit_sys::fork` -> `after_fork_parent` on `Ok(Parent) | Err` / `after_fork_child` in child **before** `blastit_sys::child::enter(plan)` -> `enter(plan)` -> `vtable.serve_view` -> `_exit`).
- **`Hosted` (wheel where CPython is already live before Stage 1, until `crates/blastit-py` is retired):** `dlopen(shim, RTLD_NOW | RTLD_LOCAL)` only (**no** `dlopen(libpython)`, **no** `gate_libpython`, **no** `init_paths`) -> `hooks = Some(loaded.hooks())` -> `fork(http)`/`fork(scheduler)` (and Stage-0 `dbproxy`/`visibility` forks) with `Some(hooks)` -> `vtable.preload` -> per-view `fork` via `Forker` (`Some(hooks)`).
- **Handle, zygote & reload semantics:** Stage 1's `Serving`/`Parts<'a>` owns `Option<LoadedPy>` and `Supervisor<'a>` borrows `Option<PyRuntime<'a>>` (`Copy` struct `(*mut PyZygoteOpaque, PyForkHooks<'a>, &'a BlastitPyVtableV1)` in `blastit-py-sapi::abi`), while `forking.rs`/`visibility.rs` take `Option<PyForkHooks<'_>>`. The shim owns the `Box::into_raw` `PyZygoteOpaque` (never dropped, never `Box::from_raw`d by `crates/blastit`, and no `free_zygote` entry may ever be added). Parent-side `vtable.check_syntax` compiles without execution (`exec_cycle` discards the parse allocation on success; rejected saves warn and return before `Ctl::Reload`). `LoadedTracker` re-`preload`s across `dev` `exec_cycle`, and `Serving` -> `Parts` -> `supervise::Adoption` is the single `(OwnedFd, OwnedFd)` owner for `Adoption.py_fds`.

## Rationale (Two Sentences)

Splitting Stage-1 load/fork order into `Embed` (`fork(http)`/`fork(scheduler)` before `dlopen`, keeping both `libpython`-free) and `Hosted` (`dlopen(shim)`-only before forks so `Some(hooks)` wraps the live wheel interpreter) lets `crates/blastit` call zero `pyo3` APIs while still running `PyOS_*Fork` under a held GIL on every interpreter-live fork. Tying `PyRuntime<'a>` to `Serving`'s `LoadedPy` without `transmute`, keeping `PyZygoteOpaque` permanently shim-owned, and holding `(OwnedFd, OwnedFd)` in `supervise::Adoption` across `dev` `exec_cycle` prevents use-after-`dlclose` and dangling-fd hazards across reloads.
