# The documented mask of the DX-invariance replay
# (`docs/design/view-crates-architecture.md` §1, `MB.36.7`).
#
# One name per line, `#` starts a comment. `crates/blastit/tests/dx_capture.rs`
# masks exactly these keys in a JSON event line, and `e2e/dx_replay.py` reads this
# same file, so the in-tree normaliser and the replay driver cannot drift; the
# suite asserts the list is the design's eight and nothing else.
#
# `ts` also masks the human log's clock (`16:18:09.360`), and the durations below
# also mask the human log's unit-suffixed numbers (`0.7ms`): they are the same
# values rendered two ways. The version banner is matched as a line shape, never
# as a field, so it does not belong in this list.
ts
duration_ms
cpu_ns
wall_ns
request_id
pid
fork_ms
cost_ns
