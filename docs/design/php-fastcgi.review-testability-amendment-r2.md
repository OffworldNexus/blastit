# `php-fastcgi` amendment review (round 2) — `testability` lens

- **Lens:** `testability` (verification and oracles)
- **Scope:** only the amendment dated **2026-11-14, labelled `MB.3.9.2`** — `docs/design/php-fastcgi.md` §1.2, §3 `R1`/`R3`/`R4`/`R20`, §4.1 (key table, error table, `SocketProbe`, probe-mapping tables), §4.8.1–§4.8.3, §7.1–§7.3, §8 (`MB.3.5.1`/`.2`, `MB.3.6.3.1`/`.2`/`.3`, `MB.3.6.4.2`, `MB.3.7`), §8.1 item 4, §8.2 rows dated 2026-11-14, and the `**Amends.**` bullets of `ADR-0008`.
- **Snapshot:** `docs/design/php-fastcgi.md` md5 `658c81516cff4fa3ccd4eabf37a67826`, **2540 lines**. Every citation below is that snapshot. (Round 1 cited a 2469-line snapshot; the file has been rewritten since.)
- **Numbering:** `T1`…`T16` below are the **round-1 amendment review's** IDs (`php-fastcgi.review-testability-amendment.md`), not §9's unrelated `testability MINOR-Tn` rows.
- **Enforcement model assumed:** named pure/unit tests, one protected suite per behaviour, `e2e/rootless/run.py` for root-only legs, `#[ignore] requires-root` elsewhere, no `php-fpm`/Docker in the fast tier.
- **Accepted premises:** `listen` gone, optional `workers`, derived socket, `resolved ≤ 64`.

## VERDICT: **FAIL**

1 `BLOCKER`, 10 `MAJOR`, 7 `MINOR`.

The named-oracle set is materially better than round 1: the listen message, the `resolved_workers` table, the at-budget twin, the 512 omission, the `down`-only override, the derived-parent symlink leg and the 512 cap check all have names and owners now. But the rewrite left **one authoritative leaf row instructing the opposite of the protected test** (`MB.3.5.1` still emits `UnknownKey` for `listen`), and the ADR has not been amended to the message or mode the design pins. Four amendment rules still have **no oracle at all** (`remove_entry`, `B2` re-entrancy, `check_leaf` per mode, production over-budget), two named oracles **cannot be written as specified** (`capacity() equals 8`, the fake-`php-fpm` `getrlimit` under a harness that excludes `S3`), and one named test's expected error/message is underdetermined (wrong-mode segment). Three §7/§8 inventories still disagree about which tests the new protected file contains.

## What holds

- The **listen** requirement itself is now correct and matches the landed code string byte-for-byte (`error.rs:512`), including "carries no value"; the only defects are the two downstream copies (T17/T18).
- The **`resolved_workers`** rule has a table test, a down-only override, an at-budget twin, an over-budget message naming both numbers, and a separate resolved-ceiling refusal — one formula with three named consumers (T20/T26 are about the consumers' observability, not the formula).
- **Nothing new needs root or a real `php-fpm` in the fast tier**: the fake `SocketProbe` keeps parent/leaf refusals unprivileged, the root-only `fchownat`/`0511`/`0600` assertions are correctly exiled to `#[ignore]`/`e2e/rootless`, and `MB.3.9.5` is specified against the fake helper.
- **Deletion genuinely reduced the surface**: `FastCgiListenInvalid`/`FastCgiListenParentInvalid`/`ParentWritableOrSymlink` are gone with the inputs they policed, and no §4.1 table row is left without an input.
- The `check -- <suite>` exit `3`, `dev` exit `1` and `check` exit `2` semantics are stated, and `critical_fastcgi_learn::config_document_carries_no_check_fd` keeps the observation-fd leak pinned.
