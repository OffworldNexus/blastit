# Lessons Learned (`docs/knowledge/LESSONS.md`)

Append one concise bullet whenever you hit a non-obvious environment, Linux privilege, Rust/PyO3, WASM, or Zensical gotcha. Read relevant entries before starting work in that area.

- **PyO3 test binaries & `libpython`:** System `/usr/bin/python3` on this host is 3.10 without a shared `libpython` on default `LD_LIBRARY_PATH`, while Blastit targets CPython >= 3.13. Always run Cargo clippy/doc/test with `PYO3_PYTHON="$(uv python find '>=3.13')"` and `LD_LIBRARY_PATH` pointing to that interpreter's `../lib` directory — `Makefile` (`make check`, `make rs-test`, `make rs-lint`) sets both automatically.
- **Offline / zero-project `uv` execution:** Root `pyproject.toml` uses the `blastit_build` maturin PEP 517 backend, so bare `uv run` rebuilds the wheel. For standalone scripts (`tools/*.py`, `e2e/*.py`), always use `uv run --no-project ...`, and for cached CLI tools (`ruff`, `zensical`) use `uvx --offline ...` so commands finish in milliseconds without touching PyPI.
- **Zensical `exclude_docs`:** `zensical.toml` builds `docs/` with `--strict` link/anchor validation. Internal agent directories (`VISION.md`, `design/`, `decisions/`, `research/`, `knowledge/`, `testing/`) are listed in `exclude_docs` so they never leak into the public documentation site or break `--strict`.
- **Zensical Mermaid shadow DOM:** Zensical renders `<pre class="mermaid">` diagrams inside a **closed shadow root**. `document.querySelector('svg')` cannot see them; visual screenshot inspection (`visual-checker` `take_screenshot`) is the only honest way to verify rendered diagrams.
- **gVisor `SO_PEERCRED` & `/proc/<pid>/environ`:** Under DigitalOcean App Platform's gVisor sentry, `SO_PEERCRED` returns the *listener's* credentials rather than the client's (use per-route `0600` listeners in `0700` dirs + `SO_PASSCRED`/`SCM_CREDENTIALS`), and `/proc/<pid>/environ` is `0444` across UIDs even with `PR_SET_DUMPABLE(0)` (so the stage-0 `execve` barrier with empty env for brokers and swapped env for stage 1 is mandatory).
