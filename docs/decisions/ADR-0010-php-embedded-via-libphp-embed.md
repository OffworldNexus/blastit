# ADR-0010: Embedded PHP Execution via Host NTS `libphp.so` and Per-Minor SAPI Shims

- **Status:** Accepted
- **Date:** 2026-11-14
- **Node:** MB.12 (supersedes all FastCGI/pool decisions in [ADR-0008](ADR-0008-fastcgi-backend-and-param-lockdown.md); implements [ADR-0009](ADR-0009-runtime-providers-and-capability-gating.md) for `MB.3` / `MB.9`)
- **Owner:** architect
- **Research:** `docs/research/php-embed-sapi.md`, `docs/research/php2shell.md`

## 1. Decision

1. **Sole PHP Backend — Embedded NTS `libphp.so` Over `view.chan` (No FastCGI, No Fallback):**
   **The only way to serve PHP in Blastit is the embedded `libphp` worker; a host without a usable `libphp` gets a boot refusal naming the package, not a degraded mode.** Blastit executes `[route.php]` routes by embedding the host's Non-Thread-Safe (NTS) `libphp.so` inside Blastit's own forked, unprivileged per-route `view` workers (`UID_BASE + 1000 + i`, `SeccompRole::EmbeddedView { egress }`, `RLIMIT_CORE=0`, private `/proc/self/cwd` where other routes' `0700` directories are `EACCES`; single-app containers must not mount host control sockets such as `docker.sock` or system D-Bus, `ARCHITECTURE.md` §1), driven through a tiny (~25 KiB, Apache-2.0) per-PHP-minor C SAPI shim (`libblastit_php{82,83,84}-<arch>-<libc>.so`, `c/include/blastit_php_abi_v1.h`: `blastit_php_worker_init` / `blastit_php_request` / `blastit_php_worker_shutdown`) where the `view` worker `dlopen`s fd-verified `/proc/self/fd/<libphp_fd>` with `RTLD_NOW | RTLD_GLOBAL` (so extensions resolve Zend symbols) followed by `/proc/self/fd/<shim_fd>` with `RTLD_NOW | RTLD_LOCAL` — **never** linked into or loaded by `init`, `http`, `scheduler`, or `dbproxy`. Requests, streaming body credits, response headers/chunks, `app.output` stderr lines, and exact per-request CPU nanoseconds (`clock_gettime(CLOCK_PROCESS_CPUTIME_ID)` around `php_request_startup`..`php_request_shutdown`) stream directly over the unnamed **`RawFrame` `view.chan` `socketpair`** (`ViewUpstream` -> `PhpEmbedRuntime`) with **no FastCGI protocol, no `php-fpm` process, and no `[route.fastcgi]` block**.
2. **Manifest Grammar & Concurrency (`[route.php]`):**
   PHP routes declare `[route.php]` with `entry = "public/index.php"` (required; **`[route.fastcgi]`, `listen`, `socket`, `port`, and `env` are rejected as unknown route keys**). NTS `libphp` runs **one request per OS process**, so the scheduler forks one single-threaded PHP `view` worker **per concurrent request** — never a fleet it pre-sizes — each under `UID_BASE + 1000 + i`. The shape is boot data written by the composition root from the admitted provider: `per_process_cap = Some(1)` and `process_pool = true` on every route whose `entrypoint php` binding is bound, bounded by `BLASTIT_MAX_WORKERS` and the memory-derived live-process cap, with idle extras retiring on `BLASTIT_VIEW_IDLE_TIMEOUT` ([ADR-0015](ADR-0015-multi-worker-views.md) decisions 1, 4, 5 and 9). The per-route `workers` cap this item used to name is **deleted, not deferred** ([ADR-0012](ADR-0012-blastfile-dsl.md) §7: a duplicate of the scheduler's budget, downward-only, unverifiable by `check`), and `BLASTIT_VIEW_MAX_WORKERS` still sizes **one** process (its `RLIMIT_NPROC` included) — it is not a per-route request lever. Post-fork `php_module_startup` per worker (`0.2.0`, so workers share zero writable SHM) is unchanged.
3. **Stage-0 Discovery (`plain_is_protected` + `.dynsym` + Pre-Scan) & Post-Barrier Stage-1 Probe Child:**
   Before binding any listener, `stage0` enforces `blastit-env`'s mandatory `BLASTIT_*` + `const ALWAYS_STRIP` set (`LD_PRELOAD`, `LD_AUDIT`, `GLIBC_TUNABLES`, `GCONV_PATH`, `LOCPATH`, `NLSPATH`, `HOSTALIASES`, `RESOLV_HOST_CONF`, `OPENSSL_CONF`, `OPENSSL_ENGINES`, `OPENSSL_MODULES`, `SSLKEYLOGFILE`, `TMPDIR`, `HOME`, `PYTHONHOME`, `PYTHONPATH`, `PYTHONEXECUTABLE`, `CLASSPATH`, `PHPRC`, `PHP_INI_SCAN_DIR`, `PHP_VALUE`, `PHP_ADMIN_VALUE`, `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY`/`NO_PROXY` families, `NODE_*`, `JAVA_*`; `LD_LIBRARY_PATH` stripped in `Production`, in `Install::Wheel` `Dev`/`Check`, and in all PHP/Node/JVM worker environments) and resolves NTS `libphp` by `open`/`fstat` + static ELF `.dynsym` inspection only (**zero `dlopen` in Stage 0**; `executor_globals` present && `tsrm_startup` absent) from `BLASTIT_LIBPHP` or, with no override, a fixed **version-major** probe list over `/usr/lib/<triplet>`, `/usr/lib64`, `/usr/lib`, the per-minor embed directories `/usr/lib/php{85,84,83}`, `/usr/local/lib/<triplet>`, `/usr/local/lib` and `/usr/local/lib/php{85,84,83}` — for each minor `8.5` → `8.4` → `8.3` the dotted (`libphp8.5.so`, `libphp-8.5.so`), packed (`libphp85.so`) and per-minor (`/usr/lib/php85/libphp.so`) spellings, then an unversioned `libphp.so` as the last resort, so a host carrying two embed packages serves from the newest library rather than refusing the first name it finds (`MB.3.61`). Two refusals belong to that gate: an NTS object whose `.dynsym` exports no `php_version` **name** is refused as exactly that, and one that exports the name but whose returned version cannot be read from the object while its path states no minor is `NoVersion` — presence is the symbol's name, the body's value is a separate fact (`MB.3.61`). A host whose `libphp` is a minor outside `8.3`–`8.5` is refused with one sentence naming that set (`MB.3.65`). In `ExecutionMode::Production`, Stage 0 validates `libphp` (zero writable `DT_RPATH`/`DT_RUNPATH`), shipped `libblastit_php8X.so`, and pre-scanned PHP `.ini` / `extension_dir` / `extension=` / `zend_extension=` targets via `host::plain_is_protected(path, init_uid)` + `!has_file_caps(path)` **before** any `php_module_startup` runs, recording `(path, st_dev, st_ino)` in `Config`. Stage 1 re-opens `O_RDONLY | O_CLOEXEC | O_NOFOLLOW`, asserts `(st_dev, st_ino)` equality, passes `OwnedFd` via `ChildIo.keep`, and forks one contained probe child per `[route.php]` route **before** `bind_tcp(0.0.0.0:$PORT)` (own `-pgid`, `drop_privileges(route_uid)`, `PR_SET_PDEATHSIG(SIGKILL)`, `RLIMIT_*`, `SeccompRole::EmbeddedView { egress }`, `BLASTIT_PROBE_TIMEOUT_MS` default `5000` -> `kill(-pgid, SIGKILL)`) running `blastit_php_worker_init` + `blastit_php_worker_shutdown` (`check` uses `Host::stage1()`'s `Reexec` `--role=php-probe` with `env = {}`, rejected in `Production`).

## 2. Consequences

- **What this deletes completely:**
  - *All FastCGI/CGI wire, param-lockdown, and `php-fpm` code:* `$_SERVER` is populated directly in C memory (`SCRIPT_FILENAME`/`DOCUMENT_ROOT` pinned, `HTTP_PROXY` omitted, query string never parsed as argv or INI, `PHP_VALUE`/`PHP_ADMIN_VALUE`/`REDIRECT_STATUS`/`cgi.fix_pathinfo` unrepresentable, `dl()` omitted), neutralizing `php2shell` (`CVE-2012-1823`, `CVE-2024-4577/8926/8927`, `httpoxy`) by construction. One PHP backend means one threat model, one CPU-accounting path, and one set of docs (`SeccompRole::Scheduler` keeps zero `socket()`).
  - *Managed-pool & fallback choreography:* Deletes `php-fpm -F -y`, `--fastcgi-parent-fd`, `S0–S7/U1`, `Ctl::Pool*`, `[route.fastcgi]`, `FastCgiUpstream`, and retires `crates/blastit-fastcgi`.
- **Hardening inside `blastit-php-sapi` & `EmbeddedView`:**
  - `zend_first_try { ... } zend_catch { ... } zend_end_try()` traps `exit()`/`die()`/fatals inside C without unwinding across Rust frames.
  - `cwd = manifest_dir` (read-only), `sapi_module.php_ini_ignore_cwd = 1`, `set_dumpable(false)` re-applied after `drop_privileges`, isolated `bt_getenv` (serving `Prepared::app_env` only, never libc `getenv`), `PATH_TRANSLATED` omitted (`PATH_INFO` single-decoded data only), and `ZEND_INI_SYSTEM` lock `allow_url_include=0`, `allow_url_fopen=0` (when `!egress`), `auto_prepend_file=`, `auto_append_file=`, `user_ini.filename=`, `expose_php=0`, `enable_dl=0`, `ffi.enable=0`, `ffi.preload=`, `display_errors=0`, `zend.assertions=-1`, `register_argc_argv=0`, `variables_order=GPCS`, `request_order=GP`, `phar.readonly=1`, `phar.require_hash=1`, `include_path=<manifest_dir>`, `sendmail_path=`, `opcache.preload=`, `opcache.preload_user=`, `opcache.file_cache=`, `opcache.jit=0`, `opcache.jit_buffer_size=0`, `memory_limit=256M`, `post_max_size=<max_body_bytes>`, `upload_max_filesize=<max_body_bytes>`, `max_input_vars=1000`, `disable_functions=exec,passthru,shell_exec,system,proc_open,popen,pcntl_exec,pcntl_fork,pcntl_rfork,pcntl_forkx,pcntl_signal,posix_kill,posix_getpgid,posix_setsid,posix_setpgid,putenv,dl`, `session.save_path=<view_tmp>`, `upload_tmp_dir=<view_tmp>`, `sys_temp_dir=<view_tmp>`, `open_basedir=<manifest_dir>:<view_tmp>`, and `max_execution_time=<request_timeout_s>` (paired with scheduler wall-clock `request_timeout` `504` + supervisor stuck-worker kill/respawn and `max_requests` recycling). `manifest_dir` and `entry` must not be writable by any route UID/GID in `Production`.
- **Pre-MC upload scope:** `raw` uploads remain reachable via `phar://` if app code itself `include`s/`unserialize`s a user-controlled upload path (`phar.require_hash=1` blocks unsigned phars, though a hash-signed malicious phar still executes under app LFI; Milestone C's WASM CDR strips polyglots before bytes reach PHP).

## 3. Rejected Alternatives

- **Bundle `libphp` inside Blastit:** Contaminates Apache-2.0 artifacts with `PHP-3.01` obligations, adds ~50 MiB, drags PHP CVEs into static/Node installs, and breaks stock distro NTS C extensions (`pdo_pgsql`, `intl`, `redis`).
- **Pure-Rust `dlopen("libphp.so")` without per-minor C shims:** `sapi_globals_struct` and `EG(bailout)` offsets shift across PHP 8.3/8.4/8.5, turning `exit()` into `SIGSEGV`.
- **`php-fpm` + FastCGI (as primary or as external fallback):** Adds daemon/socket complexity, forfeits Stage-0 secret stripping and exact CPU accounting on external pools, and splits docs/tests across two PHP models.

**Shim Naming, Boot Selection, Native CI Build & Container Deliverables (`MB.3.18`):**
> **Provenance of every count.** `scripts/platform_matrix.py` is the one place a leg is declared and the one place "proved" is recorded; `make platform-matrix-check` (part of `make check`) refuses a document that claims more artifacts than the matrix builds or more than it has built *and* exercised. As shipped: **`8` wheels, `4` standalone archives, `12` shims** declared; the x86_64 legs are built and probed (`6` shims, `4` wheels, `2` archives — see `--summary`), the aarch64 legs build and probe natively in CI on the release PR (`ubuntu-24.04-arm` runners) because a shim cannot be cross-compiled and no emulator proves `seccomp`/`fork`. A leg that fails its probe is dropped from the matrix *and* from these counts, with the reason in `MB.3.18`'s RESULT — never shipped best-effort.

**The `lsp` family is declared where every leg is, and its one numeric claim is `5` lsp assets** — the count `--check` reads once `MB.35.5` adds the noun to the gate. `scripts/platform_matrix.py` gains the `lsp` family in `MB.35.5`; this ADR names the family, the two formats and what each archive contains, while the five targets, the runner per leg and any `dropped_because` live in that module — the same rule the two serving families follow. The `8`/`4`/`12` counts above describe the serving families only; the editor family is counted by `--summary` and, once `MB.35.5` adds its own count noun, gated by `--check` like the others (never by renaming its assets "archives", which would be read against the standalone family), and its asset names, one per target, are stated once in `docs/reference/cli.md` `## blastit-lsp` and once in `docs/design/blastfile-lsp-zed.md` §8.3a. A dropped `lsp` leg means that target has **no language server** — no diagnostics, no formatting, no hover, no Quick Fix — while the grammar still colours the file; it never means a server that validates nothing.

1. **Target shim set & deterministic boot selection:** `MB.3.18` targets `3 (PHP 8.3/8.4/8.5) × 2 (x86_64/aarch64) × 2 (gnu/musl) = up to 12` ~25 KiB shims named **`libblastit_php<major><minor>-<arch>-<libc>.so`** (e.g. `libblastit_php85-x86_64-gnu.so`, `libblastit_php84-aarch64-musl.so`, zero `DT_RPATH`/`DT_RUNPATH`); each target archive/wheel bundles only the shims built and probed for its `<arch>-<libc>`. At boot, Blastit combines its compile-time `(target_arch, target_env)` with the host `libphp`'s runtime `(major, minor, NTS)` to select the exact shim; any missing/ZTS/unmatched combination **fails closed (`exit 1` / `check` `exit 2`)** naming `(PHP X.Y, <arch>-<libc>)`, the distro package (`apt install libphp-embed`, `apk add php85-embed`, `dnf install php-embedded`), and `BLASTIT_LIBPHP=/path/to/libphp.so`.
2. **Native per-platform builds & native execution tests (no cross-compiled `php_config.h`):** Generated `php_config.h` encodes platform-specific type widths, `ZEND_MM_ALIGNMENT`, and libc feature macros whose drift only surfaces as `dlopen`/struct-offset corruption at runtime. CI (`MB.3.18`) therefore compiles **and** executes the Stage-1 SAPI probe + `critical_shim_contract` + `critical_php_embed` + `make platform-matrix-check` (`scripts/platform_matrix.py`) **natively** on `x86_64` and `aarch64` runners (host for `gnu`, native-arch `alpine` containers for `musl`; up to 12 native shim build+probe legs). Note: `musl`'s `dlclose` is an intentional no-op, which is safe because the Stage-1 probe runs in a short-lived forked child that `_exit`s.
3. **Prebuilt `0.2.x` container deliverables (`MB.3.18`):** Multi-arch (`linux/amd64`, `linux/arm64`) `ghcr.io/offworldnexus/blastit:php8.4` (`debian:trixie-slim` + `libphp8.4-embed` + `libblastit_php84-<arch>-gnu.so`) and `ghcr.io/offworldnexus/blastit:php8.4-alpine` (`alpine:3.21` + `php84-embed` + `libblastit_php84-<arch>-musl.so`, gated on the checklist below) are **in-scope `0.2.x` deliverables** so Compose presets reference a ready tag without user C toolchains.
4. **Mandatory `musl` Security Gate Checklist (Drop-Not-Degrade Rule):** `musl` / Alpine is the highest-risk leg (`php84-embed` packaging, `ld-musl` `dlopen` semantics) and is **never** shipped "best effort". `MB.3.12`/`MB.3.13` must prove all six invariants on Alpine before `musl` ships:
   - **(M-1) Secrets:** Stage-0 `execve` swap and `ALWAYS_STRIP` (`LD_PRELOAD`, `LD_LIBRARY_PATH`, `PHPRC`, etc.) leave zero secrets or loader hijacks in the PHP worker's `/proc/<pid>/environ` or heap.
   - **(M-2) Isolation:** Per-route UID + `SeccompRole::EmbeddedView` install cleanly and are **never silently widened** for `musl` (if `php84-embed` requires a refused syscall that would weaken `glibc`, `musl` loses).
   - **(M-3) Egress & socket DAC:** `AF_INET`/`AF_INET6` return `EPERM` when `egress = false`, and other routes' `0700` `<runtime>/views/<other_uid>` directories return `EACCES` (container images expose no sensitive world-writable Unix sockets).
   - **(M-4) Real CPU accounting:** `CLOCK_PROCESS_CPUTIME_ID` and process-wide `/proc` (`max(pgrp_tasks_schedstat, /proc/<pid>/stat)`) work accurately (under `hidepid=2`, failing closed uniformly across all worker backends to `rlimit_nproc * wall` in `Production` / `max_workers * wall` in `Dev`, logged as `cpu_source: "ceiling"` + `Warning::ProcUnreadableCeilingFallback`).
   - **(M-5) Runtime provenance:** `libphp84.so` comes from signed Alpine community `php84-embed` with clean `ld-musl` `dlopen("/proc/self/fd/<libphp_fd>", RTLD_NOW | RTLD_GLOBAL)` + shim `RTLD_NOW | RTLD_LOCAL` resolution, zero `DT_RUNPATH` into writable dirs, and native musl-compiled shims (zero glibc-compat layers).
   - **(M-6) Effective INI/FS lockdown & CVE proof:** `ffi.enable=0`, `opcache.preload=`, `register_argc_argv=0`, `phar.readonly=1`, `phar.require_hash=1`, `disable_functions` (including `putenv` and `posix_kill`), `memory_limit=256M`, isolated `bt_getenv` (no libc `getenv` fallback), `plain_is_protected` on `/usr/lib/php84/modules` **and every loaded `.so` file**, read-only `manifest_dir`, and the full `e2e/php2shell.py` (`+ phar://` control) suite pass on Alpine.
   If **any** of `(M-1)`–`(M-6)` fails and cannot be fixed without weakening security, **`musl` is dropped outright** from the artifact matrix, CI, container tags, and docs with a 1-line recorded reason in this ADR — never shipped degraded.
