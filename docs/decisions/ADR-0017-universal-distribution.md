# ADR-0017: Universal `libpython`-Free `blastit` Binary, Per-Minor Python & PHP 8.3–8.6 Shims, Signed APT/RPM Repositories & Safe Local CLI Handoff

- **Status:** Accepted
- **Date:** 2026-11-19
- **Node:** MB.42.1. Supersedes, in part: (a) [ADR-0009](ADR-0009-runtime-providers-and-capability-gating.md) Decision 5 and [ADR-0010](ADR-0010-php-embedded-via-libphp-embed.md) §4's split between Python-linked wheels (`8` `cp3NN` wheels + `blastit-dbproxy`) and Python-less standalone archives, plus ADR-0010's `8.3`–`8.5` PHP minor ceiling (extended here to `8.3`–`8.6`, `16` PHP shims); (b) [ADR-0016](ADR-0016-view-crates-over-wire.md) Decision 6's `default = ["php", "static"]` feature split on `crates/blastit`. All runtime isolation, `view.chan` wire framing, `(st_dev, st_ino)` fd-pinning, and `SeccompRole` invariants of ADR-0009, ADR-0010, ADR-0014, and ADR-0016 stand unchanged.
- **Owner:** architect
- **Blueprint:** `docs/design/universal-distribution.md`

## Context

Through `0.2.0` pre-release builds, Blastit shipped two incompatible serving artifacts:
1. **Standalone archives** (`cargo build -p blastit --no-default-features --features php,static`) linked only `libc`/`libm`/`libgcc_s`, served PHP and static mounts, and refused every Python WSGI manifest.
2. **PyPI wheels** (`8` `cp3{13,14}` wheels) compiled `blastit` inside a CPython extension (`blastit._blastit*.so` via `crates/blastit-py`), forcing a second `blastit-dbproxy` binary inside the wheel, breaking workspace-wide `cargo build` via Cargo feature unification (`LESSONS.md` #42), and splitting every install snippet in the documentation into `# Python` vs `# PHP and static`.

Python's embedding surface can use the exact same architecture [ADR-0010](ADR-0010-php-embedded-via-libphp-embed.md) proved for PHP: a `libc`-only `blastit` binary that statically inspects the host/venv `libpython3.{13,14}` in Stage 0 and `dlopen`s fd-pinned `libpython` + a per-minor `cdylib` shim in Stage 1 **only** when a Python entrypoint/view is active. At the same time, PHP 8.6 packages (`libphp8.6-embed` on `packages.sury.org` for `debian:bookworm-slim` glibc 2.36; `php86-embed` on `alpine:edge` `testing` for musl) are now measurable end-to-end across `x86_64` and `aarch64`.

## Decision

1. **One universal `blastit` binary (`DT_NEEDED`: `libc`, `libm`, `libgcc_s`, dynamic loader only — zero `libpython`, zero `libphp`, zero `RUNPATH`).**
   `crates/blastit` removes `pyo3` and `blastit-view-python` from its dependency graph and sets `default = ["python", "php", "static"]`, where `python = ["dep:blastit-py-sapi"]` is a pure-Rust static discovery + `dlopen` loader crate sharing generic fd-pinning (`blastit_sys::pin`) and ELF `.dynsym` inspection (`blastit_sys::elf`) with PHP. Per-minor `libblastit_py3{13,14}-<arch>-<libc>.so` `cdylib` shims (`crates/blastit-py-shim`, built inside `manylinux_2_28_<arch>` / `alpine:3.21` with `pyo3/extension-module` so `Py*` symbols remain `UND` and `DT_SONAME` matches the filename) wrap `blastit-view-python` (`serve_reporting`, `immortal`, `LoadedTracker`, `PyCode::compile`, and `PyOS_{BeforeFork,AfterFork_Parent,AfterFork_Child}`) behind `blastit_py_abi_v1`. Every shipped `blastit` binary serves Python WSGI (`3.13`, `3.14`), embedded PHP (`8.3`, `8.4`, `8.5`, `8.6`), static mounts, `dbproxy`, and `lsp`.
2. **Stage-0 static Python discovery, provenance & fd-pinned Stage-1 `dlopen` (never loaded on PHP/static-only boots).**
   When — and **only** when — a Python WSGI view/app is active, Stage 0 resolves the interpreter (`BLASTIT_PYTHON` -> `$VIRTUAL_ENV` in `dev`/`check` only -> `<manifest_dir>/.venv` -> wheel `BLASTIT_WHEEL_PYTHON` -> `{python3,python}` on `PATH` in `dev`/`check`, or `/usr/local/bin`, `/usr/bin`, `/bin` in `serve`) without executing Python or calling `dlopen`. Stage 0 derives `PYTHONHOME` and `site-packages` from `pyvenv.cfg`/prefix layout, opens `libpython3.{13,14}.so[.1.0]` and `libblastit_py3{13,14}-<arch>-<libc>.so` with `O_RDONLY | O_CLOEXEC | O_NOFOLLOW | O_NONBLOCK`, validates `.dynsym` (`Py_InitializeEx`, `PyGILState_Ensure`, `PyOS_BeforeFork`, non-free-threaded) and `Production` `Provenance` (`check_objects` + `check_trees`), records `(path, st_dev, st_ino)`, and hands the open `(libpython_fd, py_shim_fd)` across Stage 0 -> Stage 1 `execve` (`--py-lib-fd`, `--py-shim-fd`; never to `dbproxy`). Stage 1 re-verifies `fstat` `(st_dev, st_ino)`, forks `http` and `scheduler` while `libpython`-free in `Embed` (`dlopen`s `/proc/self/fd/<libpython_fd>` `RTLD_NOW | RTLD_GLOBAL` then `/proc/self/fd/<py_shim_fd>` `RTLD_NOW | RTLD_LOCAL`), and follows the exact `Embed`/`Hosted` fork, `PyZygoteOpaque`/`PyRuntime<'a>`, `LoadedTracker`, `check_syntax`, GIL, and `Adoption.py_fds` invariants pinned in `docs/design/universal-distribution.md` §1.2.1.
3. **PHP `8.3`–`8.6` end-to-end (`16` native PHP shims across `4` `(arch, libc)` targets).**
   `crates/blastit-php-sapi` adds `Minor::Php86` (`806`, `libblastit_php86-<arch>-<libc>.so`, newest-first `SUPPORTED_MINORS = [Minor; 4]`); `crates/blastit-view-php::discovery` prepends PHP 8.6 probes (`LIBPHP_CANDIDATES: [&str; 13]`, `LIBPHP_PROBES: [LibphpProbe; 17]`, `/usr/lib/php86`, `/usr/local/lib/php86`, `SUPPORTED_PHP = "PHP 8.3, 8.4, 8.5 and 8.6"`, minor-aware package hints); `scripts/platform_matrix.py` declares `16` PHP shims (`("8.6", "gnu")` on digest-pinned `debian:bookworm-slim` + fingerprint-pinned Surý repo -> `/usr/lib/libphp8.6.so`; `("8.6", "musl")` on digest-pinned `alpine:edge` `testing` -> `/usr/lib/php86/libphp.so`) via a declarative `extra_repo` field.
4. **Unified `crates/blastit-audit`, pure-Python bridge & `4` universal `py3-none-*` wheels (`crates/blastit-py` and `blastit-dbproxy` bin retired).**
   Both `crates/blastit-py/src/audit.rs` and `crates/blastit/src/audit_v1.rs` consolidate into `crates/blastit-audit` (`<500`-LOC modules), leaving one grant-diff/route-trace owner. `python/blastit/_check_pytest.py` uses its stdlib ingress probe unconditionally; `python/blastit/_blastit.py` replaces the per-CPython `.so` with a fork-safe (`os.register_at_fork`) stdlib NDJSON pipe client talking to `blastit --internal-json`, and `python/blastit/__main__.py` `execve`s `blastit/_bin/blastit` (`crates/blastit-dbproxy` becomes a pure library crate). PyPI ships **`4` universal wheels** (`py3-none-manylinux_2_28_{x86_64,aarch64}.whl`, `py3-none-musllinux_1_2_{x86_64,aarch64}.whl`, `requires-python = ">=3.12"` for CLI/`check`/`fold`, while WSGI serving requires CPython `3.13` or `3.14`), built with `maturin build --bindings bin` and repacked with `blastit`, `blastit-lsp`, `4` PHP shims (`83`–`86`), and `2` Python shims (`313`–`314`) under `blastit/_bin/`.
5. **Safe local CLI handoff (`dev`, `check`/`test`, `fmt`, `lsp` only — never `Serve`, `--stage=1`, `--role=dbproxy`, `--help`, or `--version`).**
   When `BLASTIT_NO_LOCAL_HANDOFF` (`""`/`"0"` = unset) and `BLASTIT_HANDOFF_DONE` are unset, a global `blastit` running `Dev | Check | Fmt | Lsp` probes in order: (1) `$VIRTUAL_ENV/bin/blastit` when `VIRTUAL_ENV` is non-empty (ambient: no `./.venv` fallback, and a failure is a skip), else `./.venv/bin/blastit`; (2) `./vendor/bin/blastit`; (3) `./node_modules/.bin/blastit`; (4) `$BLASTIT_BIN`, last and named. Before exec, it opens the canonical parent directory `O_RDONLY | O_DIRECTORY | O_NOFOLLOW` and target `O_RDONLY | O_NOFOLLOW`, stops silently if `(st_dev, st_ino)` matches `/proc/self/exe`, fails closed (`exit 1`) only for the named `$BLASTIT_BIN` (st_uid outside `{geteuid(), 0}` or `st_mode & 0o022 != 0`), and skips an unsafe auto-discovered candidate with one `stderr` warning line so `0775` CI checkouts or third-party `node_modules` never brick `blastit dev`. Silent on valid handoff; sets `BLASTIT_HANDOFF_DONE=1` before `execveat`/`execve`.
6. **Stated & measured glibc floors, signed APT & RPM repositories (Cloudsmith + Forgejo), `install.sh` & lockfile pins.**
   `blastit`, `blastit-lsp`, and `libblastit_py*.so` build in `manylinux_2_28_<arch>` (measured floor `2.28`), while `.deb`/`.rpm` bundles measure `.gnu.version_r` across every ELF (`scripts/check-portable-elf.sh --max-glibc <shim_floor>`) and stamp `Depends: libc6 (>= <measured>)` / `Requires: glibc >= <measured>` from the bundle's real `shim_floor` (never an unverified `2.28` claim; lowering below `shim_floor` requires compiling PHP shims against a `2.28` sysroot). Packages publish to GPG-signed **Cloudsmith** (`offworld-nexus/{apt,rpm}`, `main` + 7-retained `nightly`) + non-fatal **Forgejo** mirror + GitHub Release assets. `docs/install.sh` checks `/dev/tty` (never `stdin`, which carries the `curl | sh` script) to install from the signed repo by default and falls back to `~/.local` `.tar.gz` only when `--user`/`--prefix`/`--develop`/`musl`/no-`sudo` applies. There is **one machine install** (`install.sh`/`.deb`/`.rpm`/`.tar.gz`); `uv add --dev blastit` and `composer require --dev offworldnexus/blastit` are **per-project pins** activated automatically by local handoff and upgraded via `uv lock --upgrade` / `composer update`, never `install.sh`.

## Rejected Alternatives

| Alternative | Why rejected |
|---|---|
| Bare `.deb`/`.rpm` URL download in `install.sh` instead of signed APT/RPM repos | Loses `apt-get upgrade` / `dnf upgrade` lifecycle, repository GPG metadata verification, and `main`/`nightly` channel selection. |
| Hard-code `libc6 (>= 2.28)` on `.deb`/`.rpm` carrying distro-built PHP shims | PHP shims compiled in Ubuntu 24.04/26.04 or Debian 13 bind higher glibc symbol versions (`2.39`/`2.41+`); claiming `2.28` without measuring `.gnu.version_r` fails at `dlopen` (`LESSONS.md` #58). |
| CPython Limited API (`abi3`) for `blastit-view-python` | `immortal.rs` writes per-minor `ob_refcnt`/`ob_flags` layouts and `PyOS_*Fork` / `PyCode::compile` internals outside stable `abi3`, and `abi3` still requires Python on PHP/static hosts. |
| Allow local CLI handoff on bare production `blastit` | Production `init` starts as `root` or with `CAP_*` holding real upstream secrets; executing `./vendor/bin/blastit` from `cwd` would hand PID 1 and secrets to repo files. |

## Consequences

- **Positive:** One `blastit` binary serves Python `3.13`–`3.14`, PHP `8.3`–`8.6`, and static sites; `apt`/`dnf` manage signed upgrades across `main` and `nightly`; PyPI wheel matrix halves from `8` to `4` while adding Python `3.12+` CLI/`check`/`fold` compatibility and all `4` PHP shims; rootless deployments `setcap` a `0500` copy of `blastit` (`BLASTIT_EXEC`), never `python3`; zero `uv run blastit` clutter anywhere in user docs.
- **Trade-offs:** `8` native `libblastit_py3{13,14}-<arch>-<libc>.so` shims join `16` native `libblastit_php{83,84,85,86}-<arch>-<libc>.so` shims in `scripts/platform_matrix.py`, and `.deb`/`.rpm` state the measured `shim_floor` until PHP shims are sysroot-built against glibc `2.28`.
